# Each case reads get_email_configuration(), which every mail task calls, and the from_email Django gives a message built with what it returns. A scratch Postgres on an internal Docker network, removed afterwards, and nothing was sent. The image's own api entrypoint runs configure_instance at every start, and SKIP_ENV_VAR defaults to 1 in plane/settings/common.py. checks/backend-db.sh runs with SKIP_ENV_VAR=0, so its 'default sender' PASS is case 2. A workspace's mail on the platform this repository deploys is case 4 or a sender set in god-mode, because no manifest here sets EMAIL_FROM or SKIP_ENV_VAR.
